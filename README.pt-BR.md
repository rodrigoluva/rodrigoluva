## PROJETOS

### Backend

#### Library API

Uma API RESTful de gerenciamento de biblioteca desenvolvida com FastAPI e PostgreSQL. O sistema gerencia usuários, autores, livros, exemplares e registros de empréstimo, contando com autenticação e autorização baseada em funções (RBAC).

**Foco:** Desenvolvimento de API REST • Programação assíncrona • Modelagem de banco de dados • Autenticação e autorização • Testes

**Tecnologias:** Python • FastAPI • PostgreSQL • SQLite • SQLAlchemy • Alembic • Pydantic • JWT • pytest • Docker • Kubernetes • Helm

**Repositório GitHub:** [library-api](https://github.com/rodrigoluva/library-api)

### Sistemas Embarcados

#### ESP32 OLED Gauge

Tacômetro e velocímetro digitais desenvolvidos com ESP32 e display OLED de 128×64. A rotação do motor (RPM) e a velocidade do veículo são simuladas por meio de um potenciômetro, permitindo o desenvolvimento e os testes sem a necessidade de sensores físicos no veículo.

**Foco:** Arquitetura de software embarcado • Atualização do display em tempo real • Firmware modular • Projeto de Máquina de Estados

**Tecnologias:** C/C++ • ESP32 • OLED

**Repositório GitHub:** [esp32-oled-gauge](https://github.com/rodrigoluva/esp32-oled-gauge)
