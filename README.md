### Embedded Systems

#### ESP32 OLED Gauge

A digital tachometer and speedometer built with an ESP32 and a 128×64 OLED display. RPM and vehicle speed are simulated through a potentiometer to enable development and testing without physical vehicle sensors.

**Focus:** Embedded software architecture • Real-time display updates • Modular firmware • State Machine design

**Technologies:** C/C++ • ESP32 • OLED

**GitHub Repository:** [esp32-oled-gauge](https://github.com/rodrigoluva/esp32-oled-gauge)
